# 进步小学 · 路线课堂

版本4.9.1。菜园位于教学楼南端正南方，整个菜园及旗子在楼体南侧；菜园旗与教学楼旗保持同一条南北轴线，菜园纵深缩短75%，每排4个菜篮子，共12个。南侧四旗横排、道路、校界和地图同步。宽步行路避开操场，各地点到达旗与标签统一。每段自动行走固定4秒，暂停不计时；仅点击喇叭时朗读。完整导游句子与朗读、分组路线总结、同屏方位练习、卡通知识图解、固定朝北视角与平移。南门一侧树木已移除，一米菜园在南门正西；只选择正东南西北的高亮目的地，沿直线行走。词卡、模型点选、设计站点、练习和知识图解统一方位。路线总结突出起点、方向和终点；重置当前组后回到最初出发点。
